# ShoreSense-Marine-Stranding-Bycatch-Triage
ShoreSense is an end-to-end triage assistant for marine animal strandings and bycatch, built as an educational project. It detects the species in a photo with YOLOv8, reads a typed report with TF-IDF NLP classifiers (species, condition, gear, urgency), and answers guidance questions using a LangChain + FAISS RAG pipeline powered by Groq.
